## Build order (vertical slices — do not parallelize phases)
1. **Foundation**: experiment ledger + analytics schema on the existing HQ db/event bus
   (already live — extend, don't duplicate). One canonical state; UI is a projection.
2. **Intelligence**: trend radar · viral-pattern graph (store mechanics, never copies) ·
   hook bank · content strategist. Every published asset = an experiment row
   (hypothesis, hook, CTA, views, leads, sales, learning, next test).
3. **Production**: creative director brief → script → shot list → generation → edit →
   QC. One idea = an asset constellation (short/long/carousel/thread/email).
4. **Distribution + comment intelligence** (comments are market research: question /
   objection / desire / purchase-intent → feeds hooks, FAQs, offers).
5. **Acquisition**: landing pages (one conversion goal each, A/B by angle), lead objects,
   lifecycle email.
6. **Monetization ladder**: free magnet → €7-47 tripwire (€97 audit already LIVE) →
   mid → high-ticket implementation → retainer. Value equation: raise outcome ×
   likelihood, cut time × effort. Original offers only.
7. **Optimization**: model routing, cost-per-verified-outcome, self-improvement review
   (what became more/less true, what repeats, what to stop).
